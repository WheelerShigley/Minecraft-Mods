# Window

Operators can define custom portals to link between existing dimensions!

_Note: Window does not add custom dimensions, just a way to link existing ones._

![Portal Network](https://cdn.modrinth.com/data/Idmodirx/images/6900141922d38593f0e063f8f9717e3c173b5a6b.png)

![Directions](https://cdn.modrinth.com/data/Idmodirx/images/d7b1989583ceae3c8c3fbb40274c6baacb56c1c5.png)

## Commands

![Definitions](https://cdn.modrinth.com/data/Idmodirx/images/feac1e5fb5cc55d64b2537c7826c5759157a5b08.png)

Command Examples:

> ``/win link add bidirectional gold_block fire overworld custom:farlands 1.0 yellow true``
> 
> ``/win link remove bidirectional gold_block fire overworld custom:farlands``
> 
> ``/win link list``

![Command](https://cdn.modrinth.com/data/Idmodirx/images/13d9bc412015c9300d973b16f70fb1314e57ae48.png)
