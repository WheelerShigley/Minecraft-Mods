# [SilkTouch+](https://modrinth.com/mod/silktouch+/version/1.2.1_1.21.11)
Many blocks are silk-touch-able, configurable with [gamerules](https://minecraft.wiki/w/Game_rule).

![Silktouch Spawner](https://cdn.modrinth.com/data/Gsu8eWIK/images/324c0b13911fdade5f3186933967c3d7ef0b5458.png)

## Settings
All features of this mod can be enabled/disabled with gamerules; below are their default settings.

| Name, 1.21.11+ | Name, 1.21.10- | Default Value | Tool | Effected Blocks |
| -------------- | -------------- | ------------- | ---- |---------------- |
| silktouch_budding_amethyst     | silktouchBuddingAmethyst     | true  | Pickaxe | [Budding Amethyst](https://minecraft.wiki/w/Budding_Amethyst)                                               |
| silktouch_reinforced_deepslate | silktouchReinforcedDeepslate | true  | Pickaxe | [Reinforced Deepslate](https://minecraft.wiki/w/Reinforced_Deepslate)                                       |
| silktouch_mob_spawner          | silktouchSpawner             | true  | Pickaxe | [Spawner](https://minecraft.wiki/w/Monster_Spawner)                                                         |
| silktouch_suspicious_sand      | silktouchSuspiciousSand      | true  | Pickaxe | [Suspicious Sand](https://minecraft.wiki/w/Suspicious_Sand)                                                 |
| silktouch_suspicious_gravel    | silktouchSuspiciousGravel    | true  | Pickaxe | [Suspicious Gravel](https://minecraft.wiki/w/Suspicious_Gravel)                                             |
| silktouch_trial_spawner        | silktouchTrialSpawner        | true  | Pickaxe | [Trial Spawner](https://minecraft.wiki/w/Trial_Spawner)                                                     |
| silktouch_vault                | silktouchVault               | true  | Pickaxe | [Vault](https://minecraft.wiki/w/Vault) (including [Ominous Vault](https://minecraft.wiki/w/Ominous_Vault)) |
| silktouch_infested_blocks      | silktouchInfestedBlocks      | true  | Any     | [Infested Blocks](https://minecraft.wiki/w/Infested_Block)                                                  |
| silktouch_farmland             | silktouchFarmland            | false | Any     | [Farmland](https://minecraft.wiki/w/Farmland)                                                               |
| silktouch_dirt_path            | silktouchDirtPath            | false | Any     | [Dirt Path](https://minecraft.wiki/w/Dirt_Path)                                                             |
| silktouch_cake                 | silktouchCake                | true  | Any     | \[uneaten\] [Cake](https://minecraft.wiki/w/Cake)                                                           |

These can be modified with the gamerule command, ex:
``/gamerule silktouchSpawner true``
.
